# ADR 0003: Ed25519 signatures over the raw body

- Status: Accepted
- Date: 2026-11-01

## Context

Agents run in different languages and are not terminated by a load balancer we control. Mutual TLS identifies a connection, not a particular request body, and it is awkward for short-lived developer processes. A bearer token issued by the control plane is easy to steal from an agent log and is not bound to the tool arguments.

## Decision

Each agent has an Ed25519 key. The control plane stores the raw 32-byte public key. The signature covers:

```text
<unix-seconds>.<nonce>.<lowercase-hex sha256 of the raw request body>
```

The nonce matches `^[A-Za-z0-9_-]{16,128}$`, so it cannot contain the dot separator. The timestamp must be within 60 seconds of the gateway clock. The signature is unpadded base64url. Headers are `X-AgentShield-Agent-Id`, `X-AgentShield-Timestamp`, `X-AgentShield-Nonce`, and `X-AgentShield-Signature`.

The body is hashed as received. The gateway must not re-serialize it before verification. SDKs sign the same bytes they send.

`runtime/identity` implements this and is tested. It does not store nonces. Replay protection is a Phase 1 Redis write in the gateway, with a unique key for the nonce for at least the skew window. Until that exists, the gateway must not accept signed traffic. It currently has no authorize route, which is the safe state.

Private keys are generated by the agent operator and are never sent to AgentShield.

## Consequences

Intermediaries that rewrite JSON break signatures. That is the behavior we want. SDKs in other languages must reproduce `SigningInput` exactly. The Go tests fix the field order and the hash encoding.

Clock skew beyond 60 seconds is a denial, not a retry with a fresh interpretation of the body.

## Alternatives

Bearer tokens were rejected as the primary agent credential because they are not bound to the body. mTLS remains compatible as a transport control later. It does not replace the body signature. JWT access tokens can be added as a convenience for low-sensitivity reads. They are not the credential for `authorize`.
