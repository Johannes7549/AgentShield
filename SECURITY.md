# Security policy

This repository is a Phase 0 foundation. It does not authenticate agents on a live route, and its readiness endpoints say so.

If you believe you have found a vulnerability in the implemented controls, report it privately to the maintainers. Do not open a public issue with the details. A public security contact will be added before a release that asks anyone to deploy this software.

The development credentials in `docker-compose.yml` are intentionally weak and local. Finding them is not a vulnerability.
